# Adabraka GPUI Linux

Linux and FreeBSD platform backend for [Adabraka GPUI](https://crates.io/crates/fc-gpui).

Most applications should depend on `fc-gpui`. This crate is the internal backend selected by the platform composition facade and preserves Adabraka's Wayland, X11, headless, tray, global hotkey, notification, power, dialog, and auto-launch integrations.

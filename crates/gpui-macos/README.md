# Adabraka GPUI macOS

Internal macOS platform and Metal renderer crate for [Adabraka GPUI](https://crates.io/crates/adabraka-gpui).

This package owns AppKit integration, Metal rendering, display and input handling, tray and global hotkeys, permissions, notifications, biometric APIs, auto-launch, power and network integration, and screen capture. Applications should normally depend on `adabraka-gpui` rather than this crate directly.

## 核心发现

### 提取方式
Adabraka GPUI 是从 crates.io 的 GPUI v0.2.1 开始，提取了以下 12 个 crates：
1. `gpui` → `fc-gpui`
2. `gpui_macros` → `fc-gpui-macros`
3. `collections` → `fc-gpui-collections`
4. `util` → `fc-gpui-util`
5. `util_macros` → `fc-gpui-util-macros`
6. `refineable` → `fc-gpui-refineable`
7. `derive_refineable` → `fc-gpui-derive-refineable`
8. `sum_tree` → `fc-gpui-sum-tree`
9. `semantic_version` → `fc-gpui-semantic-version`
10. `http_client` → `fc-gpui-http-client`
11. `media` → `fc-gpui-media`
12. `perf` → `fc-gpui-perf`

### Adabraka 独有功能
Adabraka GPUI 在 Zed GPUI 基础上新增了 10 大功能：
1. **系统托盘支持** - 跨平台托盘图标和菜单
2. **全局热键** - 系统级热键注册
3. **原生通知** - OS 原生通知
4. **守护进程模式** - 无窗口运行
5. **窗口控制增强** - 覆盖窗口、点击穿透
6. **自动启动** - 登录时启动
7. **单实例锁** - 防止多实例
8. **焦点窗口信息** - 获取用户焦点窗口
9. **权限查询** - 检查系统权限（macOS）
10. **图像格式特性** - 可选的图像解码器

### 文件分类
文档中将所有文件分为三类：
- **🟢 安全同步**：可直接从 Zed 复制（如 `scene.rs`, `element.rs`）
- **🟡 谨慎同步**：需要手动合并（如 `app.rs`, `window.rs`, `platform.rs`）
- **🔴 不要同步**：Adabraka 独有（如 `tray.rs`, `global_hotkey.rs`）

## 同步策略

### 推荐的同步频率
- **安全文件**：每月检查一次
- **谨慎文件**：每季度检查一次
- **依赖更新**：每季度检查一次
- **安全修复**：立即同步

### 同步优先级
1. **高优先级**：安全修复、性能改进、渲染引擎更新
2. **中优先级**：布局系统、文本系统、事件系统更新
3. **低优先级**：Zed 编辑器特定功能

### 风险管理
- 所有同步操作都在独立分支进行
- 使用检查清单确保不丢失 Adabraka 功能
- 完整的测试套件验证
- 详细的提交信息记录 Zed commit hash

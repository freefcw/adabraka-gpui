### 1. 🔴 关键 Bug 修复

#### a) Anchored 元素尺寸计算修复
**Commit**: `b38194198b` (2026-04-29)  
**影响**: 修复负坐标下锚定元素尺寸计算错误  
**文件**: `crates/gpui/src/elements/anchored.rs`

**问题**: 当子元素边界在负坐标时，最大点会被钳制到 (0,0)，导致计算尺寸膨胀  
**修复**: 使用 `Bounds::union` 替代手动 min/max 累积

**影响范围**: 上下文菜单、弹出窗口等锚定元素的定位  
**合并难度**: 🟢 低 - 独立的 bug 修复  
**建议**: ✅ 立即合并

### 2. 🎨 渲染质量改进

#### a) macOS 字形膨胀优化（基于亮度）
**Commit**: `a38fc8c8de` (2026-04-29)  
**影响**: 改进 macOS 文本渲染清晰度，特别是深色主题  
**文件**:
- `crates/gpui/src/platform.rs`
- `crates/gpui/src/text_system.rs`
- `crates/gpui/src/window.rs`
- `crates/gpui_macos/src/text_system.rs`

**改进**: 
- 复制 Core Graphics 的原生行为
- 使用 Rec. 709 公式计算前景色亮度
- 量化为 5 个级别 (0, 0.25, 0.5, 0.75, 1)
- 每个级别使用不同的膨胀因子
- 为每个字形生成最多 5 个不同的位图

**效果**: 文本渲染与 Safari、TextEdit 等原生应用完全匹配

**影响范围**: macOS 平台的文本渲染  
**合并难度**: 🟡 中 - 涉及文本系统核心  
**建议**: ✅ 强烈建议合并（显著改善用户体验）

#### b) 像素对齐（Pixel Snapping）
**Commit**: `7d42f276f2` (2026-04-24)  
**影响**: 消除非整数像素坐标导致的模糊  
**文件**: 多个布局和渲染相关文件

**改进**:
- 在设备像素空间进行舍入，确保边缘精确落在物理像素边界
- 两阶段对齐：
  1. 布局前度量对齐：舍入所有绝对长度
  2. 布局后边缘对齐：处理 flex、百分比、居中等产生的分数边缘

**效果**: 消除模糊，特别是在分数缩放因子（125%、150%）下

**影响范围**: 所有平台的渲染质量  
**合并难度**: 🔴 高 - 涉及核心布局系统  
**建议**: ⚠️ 需要仔细测试后合并（可能影响现有布局）
